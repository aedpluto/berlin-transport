# berlin-transport

This project analyses the Berlin transport network. It asks questions such as how accessible is the network to the elderly and how has the network changed over time?



Currently, the project only uses U-Bahn and S-Bahn data, although Strassenbahn and bus routes will be added at a later date.



A technical analysis can be found in the Jupyter Notebook python-analysis/mapping-berlin.ipynb (which will soon be accompanied by a written report).



This project has also been deployed on PythonAnywhere which can be accessed here: https://aedpluto.eu.pythonanywhere.com/



An older static version of the website is accessible on GitHub Pages: https://aedpluto.github.io/berlin-transport/



Demographic data was taken from the Amt für Statistik Berlin-Brandenburg (https://www.statistik-berlin-brandenburg.de/) as well as from Geodatensuche Berlin (https://gdi.berlin.de/geonetwork/srv/eng/catalog.search#/metadata/5e05b70b-50d6-4164-b0fd-9cdef4e43559).
